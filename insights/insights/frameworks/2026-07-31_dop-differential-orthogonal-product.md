## 一言で

直交する二差分チャンネルの積が非ゼロの時のみ秩序（CP）が出現する。いずれか一方がゼロになると組織化が崩壊する。

## 構造

```
DOP条件: d_u × d_v ≠ 0  →  秩序（CP, パターン, 均衡）
         d_u → 0  OR  d_v → 0  →  崩壊（Frozen or Disordered）
```

**AND型ゲート**: 二つの直交差分チャンネルがともに活性の場合のみ出力あり。

### 四ドメイン統一表

| ドメイン | 差分1（輸送/水平） | 差分2（反応/垂直） | 秩序の現れ方 |
|---------|-----------------|-----------------|------------|
| チューリング | 拡散係数比 d_v/d_u（≈10-100倍） | 反応速度比（活性化/抑制化） | 空間パターン |
| コストリーシグナル | 品質条件の拡散（模倣コスト） | 限界コスト格差（条件依存差） | 正直な分離均衡 |
| SICサイクル | S型局所強度差 | I型時間スケール差（d_I >> d_S） | C型洞察出現 |
| XPBD物理 | 剛性差分（制約強度比） | 制約密度差分（疎密比） | リアルな挙動（Coherent） |

## 数学的本体: WFR計量

WFR（Wasserstein-Fisher-Rao）計量がDOPの数学的実装:

```
WFR(ρ₀, ρ₁) = inf ∫[|v|²/ρ + r²/ρ] dμ dt
```

- `|v|²/ρ`: 輸送項（水平差分コスト）= チューリング d_v/d_u の連続版
- `r²/ρ`: 反応項（垂直差分コスト）= コストリーシグナル限界コスト差の連続版

WFR ≠ 0 ⟺ DOP条件充足 ⟺ CP存在

## 使いどころ

1. 「なぜこのシステムは秩序を持つか？」 → 二種類の直交差分を同定し、その積がゼロでないか確認
2. 「なぜ崩壊した？」 → どちらの差分チャンネルが消失したかを特定
3. ゲームデザイン: プレイヤーの報酬差分（縦）× スキル差分（横）の両立がリテンションを決める
4. 教育設計: 課題難易度差分 × 能力ばらつき差分の積が学習体験の質を決める

## 予測

**P-DOP-XPBD-01**: XPBD シミュレーションで剛性差分（高剛性部位/低剛性部位の比）× 制約密度差分（制約の粗密比）のどちらかを均一化すると、Coherent Phase（リアルな動き）が消える。
反証条件: 一方の差分のみでCoherent Phaseが維持できるケースが存在する場合。

**P-DOP-EDU-01**: 教育設計で課題難易度分散（差分1）と学習者能力分散（差分2）の積が低い時（均質クラス×均質課題）、深い学習（CP型）が出現しない。
反証条件: 均質環境でも深い学習が系統的に出現する場合。
