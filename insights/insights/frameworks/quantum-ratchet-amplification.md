## 一言で

**微小な初期非対称性が散逸フィードバックで自己強化され、不可逆な対称性破れを創る。**

## 構造（4要素）

```
[1. 種（微小な非対称性）]
    ↓ (増幅子が種を入力として要求)
[2. 増幅子]
    ↓ (出力が基質を変化させる)
[3. フィードバック基質]（書き込み可能な媒体）
    ↓ (基質の変化が増幅子をさらに効率化)
[2. 増幅子] （強化された）
    ↓ (ループが閾値を超えると...)
[4. 散逸による不可逆化]（エントロピー排出）
    ↓
非対称安定状態（ロックイン）
```

**重要構造的命題**: 「増幅子は下層の種晶なしに出力できない」
→ これが CLHPC の発達カスケード（下から上へ）の機構的理由

## QRA の失敗条件（P-006修正から一般化）

1. **種なし（Seedless）**: 初期非対称性 = 0 → ラチェット起動不可
2. **増幅子弱すぎ（Weak Amplifier）**: ノイズに負ける → 揺らぎが対称状態に戻す
3. **散逸なし（Non-dissipative）**: 閉鎖平衡系 → 熱力学的に不可逆化できない

**P-006の教訓**: 「高スピン緩和」は主因ではなく、「磁性基質なし = 種晶欠如（条件1違反）」が主因だった。

## CP との関係（重要な逆説）

**QRA ≠ CP のように見えるが、実は「生命の二相構造」として共存**:

```
Phase A（QRA ラチェット期）: 下位層を Frozen させる
  例: CISS → ホモキラリティ Frozen
  例: Hebbian + PNN → Layer 0 Frozen
  これは意図的な Frozen 化、CP とは逆方向

Phase B（CP 保護期）: Frozen 基盤の上でフロッピーモードを保護
  例: ホモキラリティ基盤の上で多様な生命形態が花開く
  例: Layer 0 Frozen の上で Layer 1, 2 が創造的に探索
  これが CP 本来の機能
```

**結論**: Layer 0 が Frozen であることが Layer 1-2 の CP を可能にする基盤となる。
QRA（Frozen創造）と CP（floppy保護）は対立ではなく、二層構造の上下に対応。

## 限界

- **定量化が難しい**: 「種の大きさ」「増幅子の効率」「散逸速度」を独立に測定する方法が分野によって異なる
- **時間スケール依存**: QRAが走る時間スケールが短すぎると種が揺らぎに飲まれる。長すぎると外部環境変化で基質が壊れる
- **CP との境界**: いつ Phase A が終わって Phase B が始まるかの指標が未定
- **逆転可能性**: 十分に大きな外部介入（エピゲノム編集、社会革命）で QRA ロックインを強制的に解除できる場合がある
- **確率的ロックイン**（2026-07-13 P-QRA-01から修正）: ロックインは決定論的でなく確率的。後期L2習得で5-10%がnative-like達成 = escape_probability > 0。修正: 「臨界期 = ロックイン確率が急上昇する時間窓（ただし escape_prob は 0 にはならない）」。推定関数形: escape_prob ≈ 1 - tanh(amplifier_efficiency × hysteresis × elapsed_time)
- **適用ドメイン条件**（2026-07-13 P-QRA-01から修正）: QRAは「フィードバック速度 >> 環境変化速度」の系でのみ明確な臨界期を生む。文化規範のような低速拡散系では両速度が同程度のため、臨界期が不明瞭になる（連続変化に見える）。神経系・市場ネットワーク系のような高速フィードバック系では鋭い臨界期が現れる
