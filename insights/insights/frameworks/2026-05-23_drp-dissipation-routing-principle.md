## 一言で

**失敗エネルギーの流路設計が変容の可否を決める。**

CDM×CTW×AGP×散逸チャネルは、すべて「失敗という散逸エネルギーがどの方向へ、どのタイミングで、どの地形へ流れ込むか」という一命題の異ドメイン記述だった。

---

## 構造

### CTW原理ファミリーの依存グラフ

```
CDM原理（入力条件）
└─ 失敗 = 地形labilizationトリガー
   └─ CTW原理（時間窓）
      └─ 可塑性はlabilization後の時間窓の中でのみ開く
         ├─ AGP（方向ゲート）
         │  └─ 内的帰属 → CTWが機能 / 外的帰属 → CTW封鎖
         │     └─ AGP精密化（質ゲート）
         │        └─ 内的×制御可能（努力帰属）→ CTW開放
         │           内的×制御不可能（能力帰属）→ CTW内側封鎖
         └─ CTW-Flow逆説（排他的状態）
            └─ Flow中 = CDMトリガー入力なし = CTW到達不可
```

### DRPのサブ原理対応

| 下位原理 | DRP内の役割 |
|---------|------------|
| CDM原理 | 流路への入力条件（失敗規模・予測誤差の適切さ） |
| CTW原理 | 流路が有効な時間窓の定義 |
| AGP | 流路の方向ゲート（内側か外側か） |
| AGP精密化 | 内部流路の質ゲート（可変地形か固定地形か） |
| 散逸チャネル自己遮断 | 流路の構造的閉鎖（組織・制度レベル） |
| CTW-Flow逆説 | 流路の排他的状態（Flow中はCDM入力がない） |
| Shell Persistence | 新地形の自発的保存（流路閉鎖後の固定） |

### Frozen維持の三戦略（流路遮断の三実装）

変容への抵抗はすべて「流路遮断」の多様な顔だ:

| 戦略 | 実装レベル | 機構 |
|------|-----------|------|
| CDM回避（失敗を避ける） | 個人行動 | 失路への入力を断つ |
| AGP外的帰属化 | 認知・態度 | 流路を外向きにする（内側に向けない） |
| 散逸チャネル自己遮断 | 組織・制度 | 流路の構造ごと破壊する |

三者のどれが欠けても変容は起きない。三者は独立した介入を要求する。

## 重要な発見：熟達のFlowはFrozenへの正門

プロゲーマーや熟練者がFlow状態を維持するとき、CDMトリガーへの到達が起きない。
Flowは「既定スキルの自動実行モード」（transient hypofrontality）であり、失敗が発生しないため地形のlabilizationが起きない。

**「スキルが高いほど、CDMトリガーを自分で設計しなければならない」**

これがDeliberate Practiceの神経科学的根拠: Ericssonが「居心地の悪い練習」と言ったのは「自発的CTW開放設計」のことだった。さらにAGP精密化を加えると、Deliberate Practiceは「難易度だけでなく、失敗の帰属先が内的×制御可能になる設計まで含む」必要がある。コーチが技術的に失敗原因を解析する環境提供は「AGP保証の場の設計」だった。

## 限界

1. **マインドセット変容の再帰問題**: DRPは「AGP質ゲート（帰属スタイル）が可変」であることを前提とする。しかしマインドセット自体が固定（Frozen）の場合、DRPは適用不能——先に帰属スタイル変容が必要。これは「CTWをCTWで変える」再帰問題として独立した難問。

2. **トラウマでのAGP二段階**: 能動的失敗（学習文脈）では内的帰属がCTW開放に必要。しかし受動的被害（トラウマ）では「これは自分のせいではない」（外的帰属）が適切な地形保護になる。DRP適用はトラウマ文脈で二段階モデルを要求する: まず外的帰属による保護、次に「回復に向けて自分は何ができるか」という内的×制御可能帰属へのシフト。

3. **スケール境界問題**: 個人のAGPが内的帰属でも、組織が外的帰属を制度的に強制する場合（「構造の問題」という一元的帰属化）はDRPが働かない。個人介入と組織介入の独立性。

4. **未実装次元**: WeinerのAGP精密化に「安定性」次元（一時的/恒久的）が欠落。「この失敗は今回だけか恒常的か」の知覚がCTWの時間的長さに影響するはず（P-AGP-03候補）。
