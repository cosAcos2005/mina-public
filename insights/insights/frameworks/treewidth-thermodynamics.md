# 木幅熱力学 (Treewidth Thermodynamics)

> **発見**: 2026-07-25 第59セッション（Deep Dive）
> **起源**: Robertson-Seymour定理 × Junction Tree × Landauer原理 × Sagawa-Ueda × 自然選択
> **一言**: 推論の熱力学的コストは exp(tw) に比例する — これが全ドメインに木幅が現れる理由

---

## 中心定理（仮説）

相互作用グラフ G 上の推論の最小熱力学的コストは:

> **E_inference ≥ n · |Ω|^(tw(G)+1) · kT · ln2**

ここで:
- n: 変数数
- |Ω|: 各変数の状態空間サイズ
- tw(G): グラフ G の木幅
- kT · ln2: Landauer限界

## 導出チェーン

```
Robertson-Seymour定理
  → グリッドマイナーは木幅で制御される（Grid-Minor定理）
    → Courcelle定理: tw有界 ⟹ MSO₂決定可能
      → Junction Tree: 推論計算量 O(n·|Ω|^(tw+1))
        → Landauer: 各計算ステップ ≥ kT·ln2
          → E_inference ≥ n·|Ω|^(tw+1)·kT·ln2
            → 自然選択: tw削減に指数的有利
```

## 三つの系

### 系1: Sagawa-Ueda効率
フィードバック制御の効率 η は木幅の指数関数で減衰:
> η ∝ 1 / |Ω|^tw

低木幅モデルほど同じ相互情報量 I(X;Y) から多くの仕事を抽出可能。

### 系2: FIMブロック分解
グラフィカルモデルのFisher情報行列は木分解のクリーク構造でブロック対角化可能。
- tw ≤ t → 自然勾配 O(n · (t+1)³)
- tw = n → 自然勾配 O(n³)

### 系3: 変分推論階層
変分近似の精度-コストトレードオフは木幅でインデックスされる:
| 手法 | 実効tw | コスト | 精度 |
|------|--------|--------|------|
| Mean field | 0 | O(n) | 最低 |
| Bethe/Loopy BP | 1 | O(n·|Ω|²) | 中 |
| Structured VI | k | O(n·|Ω|^(k+1)) | 高 |
| Junction Tree | tw(G) | O(n·|Ω|^(tw+1)) | 厳密 |

## CP構造の再導出

木幅熱力学はCP理論を使わずにCP構造を再導出する:
- **tw = 0**: 全変数独立 → Frozen（構造なし）または Disordered（自由度過剰）
- **tw_opt**: 精度-コスト比最大 → **CP帯域**（HOW制約の最適量）
- **tw → ∞**: 計算不能 → Disordered（推論崩壊）

## 適用ドメイン

- **タンパク質折り畳み**: 接触グラフ tw ≈ 3-10、折り畳み速度 ∝ exp(-tw)
- **RNA**: 非交差(tw≤2) → O(n³)、擬似結節(tw≥3) → NP困難
- **脳**: 階層的予測的符号化 = 推論の木分解の神経実装
- **言語**: 射影制約 = 依存グラフ木幅制限
- **進化**: 機能単位の木幅は全体ネットワークより有意に低い

## 文献ギャップ

木幅と計算量の関係（Courcelle, Junction Tree）、情報と熱力学の関係（Landauer, Sagawa-Ueda）は各々確立済み。しかし**木幅 → 熱力学的推論コスト**の直接接続は既存文献に存在しない（7研究エージェントで確認）。
