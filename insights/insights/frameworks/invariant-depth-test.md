## 一言で

同一不変量を共有すれば深層原理、形が似ているだけなら翻訳的Bisociation。

## 構造

接続の深さを判定する操作的基準:

```
接続A-B を発見したとき:
  ↓
「AとBが共有する不変量（関数形・指数・保存量）を特定できるか？」
  ↓
  Yes → 同一不変量 → 深層原理（Deep Principle）
  No  → 形が似ている → 翻訳的Bisociation（Translational Bisociation）
```

### 「同一不変量」の基準

数学的: 同一の関数形（not similar, but identical）
物理的: 同一の保存量・対称性クラス
情報的: 同一の指数（α, H, det(G) の振る舞い）

### なぜこの区別が重要か

翻訳的Bisociationは**探索ツール**として有用。「AとBは似ている → Bの知見でAを照らす」という認知ジャンプを可能にする。

深層原理は**説明力**を持つ。なぜAとBが同じ振る舞いをするかを統一的に説明できる。

CPエコーチェンバー対策: 「全てがCPに繋がっている」という直感の多くは翻訳的Bisociationの段階。不変量の同一性を確認するまでは深層原理と呼ばない。

## 使いどころ

| 場面 | 使い方 |
|------|--------|
| 新しい接続を発見したとき | 不変量を特定できるか自問。できなければ翻訳的Bisociationとして保存 |
| 既存の類比を評価するとき | 「これは教科書に載る深層原理か、それとも探索的な類比か」を判定 |
| 蒸留できない発見を pending に入れるとき | 「不変量特定後に蒸留可能になるかもしれない」と注記 |

## 発見の経緯

GUEペア相関関数（ランダム行列理論）とリーマン零点のペア相関（数論）は:
```
1 - (sin πr / πr)²
```
という**完全に同一の関数形**を持つ。これはモンゴメリー-オドリツコ法則の核心。

これに対して、「1/fノイズとCP構造の類似」は指数が「α≈1付近」という近似的な一致であり、関数形の完全一致ではない。

前者は深層原理（同一の数学的対象が別の服を着ている）。後者は翻訳的Bisociation（相互照射で探索を深める）。

この違いを意識することで、Bisociationの品質評価が可能になる。

## 適用例

| 接続 | 不変量 | 判定 |
|------|--------|------|
| GUEペア相関 = 零点統計 | 1-(sinπr/πr)² (完全一致) | 深層原理 |
| 1/fノイズとCP | α≈1 (近似) | 翻訳的Bisociation |
| Coulomb反発 = det(G)>0 | Vandermonde行列式 = Fisher計量の行列式（検証中） | 深層原理候補 |
| autopoiesis = Yoneda = CP引力子 | 自己維持閉ループの同一構造（既蒸留） | 深層原理 |
| Frozen = 組織腐敗 | 類比的類似 | 翻訳的Bisociation |

## 限界

- 「不変量の同一性」自体が抽象度に依存する。高い抽象度では全ての対象が「同一不変量」を持てる
- 翻訳的Bisociationも重要な認知ジャンプを可能にする。「低い価値」を意味しない
- 深層原理だと判明しても、なぜ同一不変量を持つのかという説明が別途必要（e.g., GUE=零点の理由は未解明）
