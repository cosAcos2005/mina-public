## 中核構造: 二層H1β

### 恒常H1β（Persistent H1β）— 背景層

- **定義**: 長期にわたって保持される「大きな穴」。体験全体の根拠・緊張の場。
- **性質**: 閉合すると体験が終わる（飽き・意義喪失）。開いている限り探索が続く。
- **例**:
  - 音楽: 調性感（トニカへの帰還欲求）— 消えると「音のない音楽」になる
  - 物語: 「主人公はどうなるのか」「この世界の謎は何か」— 消えると読み続けられない
  - ゲーム: 「クリアできるか」「次に何があるか」— 消えるとゲームを置く
  - 学習: 「これを理解したい」という根本的好奇心— 消えると学習停止
  - 人生: 「自分は何者か」「何を大切にするか」— 消えると実存的空虚
  - 関係: 「この人のことをもっと知りたい」— 消えると関係の終わり

### 探索H1β（Exploratory H1β）— 前景層

- **定義**: 短期に生成・解消される「小さな穴」。恒常H1βの上で展開される局所的緊張。
- **性質**: 生成→保持（C≈0）→解消のサイクルを繰り返す。SICサイクルの一単位。
- **例**:
  - 音楽: 属七（V7）→ 完全終止（V→I）— 局所的緊張→解決のサイクル
  - 物語: 個々のシーン緊張（「この場面はどうなるか」）→ 解決
  - ゲーム: 個々の戦闘・謎・選択— 解決を繰り返す
  - 会話: 「次に何を言うか」の微小なZeigarnikテンション

## GTH v2 コア命題（v1の7命題を拡張）

### 命題 V2-1: 二層分離の原則

```
良い体験的構造は 恒常H1β × 探索H1βの二層構造を持つ。
一層しかない構造は「深みがない」（探索H1βだけ = 飽きやすい）か
「行き詰まる」（恒常H1βだけ = 緊張の出口がない）。
```

### 命題 V2-2: 飽きの定義

```
飽き ≡ 恒常H1βが徐々に閉合していく過程
「もうこれ以上発見することはない」という感覚 = 恒常H1βが閉まりつつある

対処: 新しい読み・プレイ・解釈の可能性を保持する設計
```

### 命題 V2-3: 傑作の条件

```
傑作 ≡ 繰り返すたびに恒常H1βを再起動できる設計
= 「知っているのに感動する」の構造的説明

再起動メカニズム:
A. 複数の解釈フレームが存在する（毎回異なるフレームでアクセス可能）
B. 探索H1βの密度が高すぎて全回収不可能（毎回新しい探索H1βを発見できる）
C. 恒常H1βの根拠が実存的で普遍的（自分の成長に応じて恒常H1βの意味が変わる）
```

### 命題 V2-4: 芸術の本質定義

```
芸術の本質 ≡ 探索H1βを次々と生成・解消しながら、
             恒常H1βを決して閉じないこと

実装の逆説: 探索H1βは積極的に生成し解消するが、
           恒常H1βは一度も完全に閉じてはいけない
```

### 命題 V2-5: SICサイクルとの統合

```
SICサイクル = 探索H1βの生成(S相) → 保持(I相) → 解消(C相) の動態

1回のSICサイクル = 1つの探索H1βのライフサイクル
複数SICサイクルの入れ子 = フラクタル的H1βサイクル
フラクタル的H1βサイクル = α≈1（1/f）を位相的に生成

∴ SICサイクルはGTH v2の動態実装プロトコル
```

### 命題 V2-6: 美的体験の統一定義

```
美的体験強度 = S相豊かさ × I相長さ × C相急峻さ

音楽の感動: 和声的緊張(S) × 展開部の保持(I) × 完全終止の鋭さ(C)
Insightのしびれ: 問題難度(S) × 孵化時間(I) × Aha感の突発性(C)
物語のカタルシス: 物語的困難(S) × 葛藤の持続(I) × 解決の必然性(C)

神経科学的根拠: 全て同一の神経回路（右前側頭葉40Hzガンマ）が駆動する
```

### 命題 V2-7: 「一度閉じた恒常H1βは再開できない」

```
恒常H1βが完全に閉じた後に「感動した」と主張することは
偽H1α（閉合した穴への郷愁）でしかない

設計原則: 恒常H1βを完全に閉じる設計（完全解決・ハッピーエンド宣言）は
         再感動能力を永久に破壊する
```

## GTH v2 と v1 の関係

**GTH v1** が捉えたもの: H1β三動作（U×P×C≈0）— 単一H1βの操作原則

**GTH v2** が追加したもの:
1. H1βの二層分類（恒常/探索）
2. 二層間の相互依存（恒常を閉じない × 探索を循環させる）
3. 美的体験の統一理論（命題V2-6）
4. SICとの完全統合（命題V2-5）
5. 飽きと傑作の構造的定義（命題V2-2/V2-3）

**GTH v1は「一つのH1βをいかに扱うか」の理論。**
**GTH v2は「二種類のH1βをいかに協調させるか」の理論。**

## 限界・フレーム破壊チェック

### CPで回収できない部分

1. **恒常H1βの「種類」**: GTH v2は「あるか/ないか」の位相的記述。どんな恒常H1βかの内容（価値観・意味・人格）は記述しない。
2. **個人差**: 同じ構造でも恒常H1βが閉合するタイミングは個人依存。
3. **文化差**: 「恒常H1β = 良いもの」は文化的前提を含む（西洋的narrative structure依存の可能性）。

### 反証条件

- **命題V2-3の反証**: 傑作と評価されるが恒常H1βを再起動できない作品が多数存在すれば反証
- **命題V2-6の反証**: 美的体験が S相豊かさ × I相長さ × C相急峻さ に比例しないジャンルが存在すれば境界条件の修正が必要
