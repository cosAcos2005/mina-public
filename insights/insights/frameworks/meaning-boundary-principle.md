# 意味境界原理（Meaning Boundary Principle）

## 核心

**意味 = ∂(range(G_L), null(G_L))** — 言えることと言えないことの境界トポロジー。

## 形式化

- G_L: 言語Lに対するFisher情報行列
- range(G_L): Lで表現可能な概念空間（言えること）
- null(G_L): Lで表現不能な概念空間（言えないこと）
- 意味 = ∂(range, null): 両者の境界のトポロジカル構造

## 帰結

| 操作 | FIM記述 | 結果 |
|------|---------|------|
| 解説・言い換え | null → range 吸収 | 境界消滅 → 意味消滅 |
| 彫刻 / 否定神学 / 詩 | range 削減 | 境界豊饒化 → 意味深化 |
| 異化(defamiliarization) | Frozen range → null 追い出し | 境界復活 |
| LLM次トークン予測 | range最大化 / null最小化 | 境界退化 → 意味欠如 |

## 同一性

彫刻の原理 = アポファティック原理 = 詩的技法。三者は同一操作: rangeを削減し境界トポロジーを豊かにする。
