## 一言で

可塑性は定常状態ではなく遷移状態にのみ起きる。
CTW・クリティカル期間・サイケデリクスは全て、Labilization→Window→Restabilizationの三相構造を持つ異機構・同型の可塑性プロトコルだ。

## 構造

```
L (Labilization / 脱固化)
  ↓
W (Window / 可塑性感受性の高い期間)
  ↓ ← 経験入力（必須。なければ変化しない）
R (Restabilization / 再固化)
  ↓
新しい安定状態
```

### 三相の定義

**L: Labilization（脱固化）**
- 現在の安定状態（引力子）を一時的に不安定化する操作
- 機構は異なっても機能は同一:
  - CTW（記憶再固化）: 記憶想起による再活性化・脱安定化
  - クリティカル期間（発達）: PNN未形成、SOC活動による可塑的状態
  - サイケデリクス: ECMリモデリング（PNN融解）によるFIM零固有値解放

**W: Window（可塑性感受性窓）**
- 脱固化後の「変化への感受性が高い期間」
- 可塑性"そのもの"ではなく"感受性"が増す（Acuna 2025の実証）
- 窓長はLabilizationの深度に依存（表面的変化 → 短窓、骨格変化 → 長窓）
- 典型的な長さ: 数秒〜数週間（機構依存）

**R: Restabilization（再固化）**
- 経験入力に依存した新しい安定状態への収束
- 入力なければ元の状態に戻る（または不定安定状態に）
- 「何を学ぶか」はRが決める（Labilizationは「どの程度感受性を高めるか」しか決めない）

### FIM幾何的記述

```
L: FIM固有値スペクトルの一時的低下 → フロッピーモード増加
W: 低固有値（高フロッピーモード）状態の持続
   → 入力ベクトルの方向にFIM零固有値が向きやすい状態
R: 経験入力方向へFIM固有値が再成長 → 新パターンでの高固有値安定化
```

## 既存フレームワークとの関係

**SICサイクルとの関係**:
- SIС（Struggle-Incubation-Crystallization）はLWRのL2（認知層）表現
- FICプロセス（Fluidization-Imprint-Crystallization）はLWRのL0（生化学層）表現
- LWRはスケール中立の普遍型（どの層にも適用可能）

```
L0（生化学）: FIC = Fluidization → Imprint → Crystallization
L2（認知）:   SIC = Struggle    → Incubation → Crystallization
普遍型:       LWR = Labilization → Window → Restabilization
```

**RBD（感受性ブースト設計）との関係**:
- LWRは「何が起きるか」の記述フレーム
- RBD（Receptivity Boost Design）はLWRをどう設計するかの実践フレーム

```
RBD三要素:
1. Unfreezing設計（L相の制御）
2. Window管理（W相の長さ・質の設計）
3. Targeted input（W中の最適経験提供）
```

**V-Growthとの関係**:
- LWRはV-Growth（垂直成長）の機構的記述
- L-Growth（水平成長）はLabilizationなしの定常可塑性
- V-Growthにはフレーム変容が必要 = Labilizationが不可欠

## 使いどころ

- 「なぜこの学習は定着しないのか？」→ W中のR（再固化入力）が不適切か存在しないから
- 「なぜサイケデリクスだけでは治らないのか？」→ Labilizationは達成したが経験入力（R）が設計されていないから
- 「どれくらいの期間で教えるか？」→ Labilization機構の窓長（W）を把握してから設計する
- 「変革はなぜ失敗するか？」→ L（変革ショック）だけあってW中のR（ビジョン入力）が欠如しているから

## 限界

1. **LabilizationのL多様性問題**: CTW（認知操作）、クリティカル期間（発達プログラム）、サイケデリクス（外因性化学）は質的に異なる。「同型」の主張が表面的類似に留まる可能性がある。反証候補: LWRの三相が独立操作可能な実験系（L×W×Rをそれぞれ独立変化できる）で、片相の変化が他に影響しないことが示されれば「三相は独立」= LWRより単純な二成分（+入力）で説明可能。

2. **入力なき再固化の存在**: 経験入力なしに再固化が起きる（スポンタニアスリプレイ等）可能性があり、純粋な「入力依存性」には反例候補がある。

3. **窓長の個体差**: ECMゲル化速度には個人差・年齢差・経験差がある。「窓長は機構で決まる」は集団平均の記述。

## 予測（P-LWR-01）

LWRの三相が独立操作可能なin vitro神経回路または行動実験系で:
- L操作あり + W中入力あり → R後に変化あり
- L操作あり + W中入力なし → R後に変化なし（または元の状態に戻る）
- L操作なし + 入力あり → R後に変化なし（または小さい）

この三条件の差が有意ならLWRの三相独立性と普遍性を支持する。
