## 一言で

「X が Y を記述できるとき、X が Y を生成/引き起こしていると言えるか？」という型の問い。数学的記述と機構的因果を区別する認識論的フレームワーク。

## 構造

**問いの型**: X（記述体系/数学）が Y（現象）を精確に記述できる → しかし X が Y を「動かしている」と言えるか？

**5つの区別基準**（Opus Phase 2 由来）:
| 基準 | 判定方法 | 例（機構○ / 記述×） |
|------|---------|-------------------|
| A ハミルトニアン参入 | MがダイナミクスのODEに入っているか | QEC群構造○ / Grimm's Law Z₃× |
| B 反事実テスト | Mを除去したら振る舞いが変わるか | スタビライザー○ / Z₃× |
| C 生成か実現か | Mが現象を生成か、現象がMを実現か | IFSフラクタル○ / 海岸線フラクタル× |
| D 独立実装可能性 | 別の物理基盤で実装しても同一効果か | QEC（光子/SC/イオン全て機能）○ |
| **E 収束する動的過程への参加**（最有力・改訂版） | Mが関与する均衡を実現する収束する動的過程が存在し、Mがその過程に参加しているか | QEC測定ループ○ / シグナリング分離均衡○ / Z₃群× |

**CPフレームの位置**: pragmatic realism（記述より強く、機構より弱い）
→ 「dagを読む道具——dagを動かすのは別のプロセス」

## 使いどころ

| 状況 | 問うべきこと |
|------|------------|
| 「数学的構造がシステムに入っている」と感じた時 | 「閉ループ因果性基準（E）を満たすか？」 |
| 「この理論はこの現象を説明できる」の強さを評価する時 | 「記述か機構か、基準A-Eでテストする」 |
| CPエコーチェンバー対策 | 「CPフレームがこの現象を動かしているか？それとも読んでいるだけか？」 |
| 新しい数学的接続を発見した時 | 「これは美しい記述か、それとも機構的な接続か？」 |

## 適用例

| ケース | 判定 | 基準 |
|------|------|------|
| QECのスタビライザー群 | 機構 | A（ハミルトニアン参入）+ E（測定→訂正→再測定ループ） |
| Grimm's LawのZ₃群 | 記述 | E基準不成立（閉ループなし） |
| Coltrane ChangesのZ₃対称性注入 | 機構 | E（演奏者が継続的に閉ループを回す） |
| CPフレーム全体 | pragmatic realism（記述以上・機構未満） | A不成立、Bは介入予測として部分成立 |
| Fisher多様体上の自然勾配流（Replicator Dynamics） | 機構的 | Cの「生成」側——動力学方程式がどこに向かうかを決定 |
| 自然選択（Sober 1984 vs Matthen & Ariew 2002） | 論争中 | 進化生物学での DG境界問題の典型事例 |

## 2026-07-04 Opus深層思考による改訂

**基準E改訂**: 「閉ループ因果性」→「収束する動的過程への参加」に精密化。Bongers-Mooij（2021）の「均衡化は介入と可換」が形式的根拠。

**動的DG遷移原理**: DG状態は固定的でなく、動的過程の有無で遷移する。
- 記述→機構: 動的過程が開始する（ポンプ点火）
- 機構→記述: 動的過程が停止する（Shell Persistence = 構造は残るが動的地位を失う）

**三経路**: コスト経路（進化的/学習的フィードバック）、利害一致経路（反復的信頼フィードバック）、顕著性経路（文化的学習フィードバック）。det(G)三モード（能動/受動/位相的）と構造同型。

## 限界

- 基準Eの「収束する動的過程」の形式的定義はBongers-Mooijで改善されたが、「参加」の境界は依然として完全には形式化されていない
- DG境界は絶対的でなく文脈・実装・内面化依存の可能性（法哲学例）
- セルオートマトンのような「計算的文脈」では区別が崩れる
- 「攻守二面性の形式化」に直結するが、数学的証明はまだない
- 三経路間のDGスコア関数形（加算的？積的？OR型？）が未特定
