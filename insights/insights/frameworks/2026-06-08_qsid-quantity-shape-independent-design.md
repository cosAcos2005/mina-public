# QSID原則（量-形独立設計原則）

## 一言で
**強さだけ上げても形が通らない。変容設計ではκ（量）とσ（形）を独立した軸として扱え。**

## 構造

### 核心命題
変容設計において「どれだけ強い刺激が必要か（κ）」と「どんな形の刺激が効くか（σ）」は**独立した設計変数**。既存の設計の大半はκ軸しか扱っていなかった。

### 2×2設計マトリクス

| | κ高（強い刺激） | κ低（弱い刺激） |
|---|---|---|
| **σ高（多様な形が通過可能）** | ✅ 最適設計（難しく、形の制約も緩い） | ⚠️ σ単独失敗（「なんでもあり感」で達成感なし） |
| **σ低（特定の形のみ通過）** | ❌ **典型的失敗**（燃え尽き/拒否反応/形式的コンプライアンス） | ❌ 変容なし |

「κ高/σ低」が既存設計の**最も多い失敗パターン**。
「難易度上昇だけのDLC」「危機感醸成だけの変革要求」「スパルタ指導」がここに落ちる。

### 既存DRP/CTW/AGP体系の再配置

QSID原則によって、既存の原理群が**2軸に機能分離**できることが明確になった:

```
κ軸の工学:
  CTW（Controlled Thaw Window）— labilizationが起きる時間窓の制御
  DRP（Dissipation Routing Principle）— 失敗エネルギーの流路設計
  PE強度設計 / Goldilocks窓の位置操作

σ軸の工学:
  AGP（Attribution Gate Principle）— どの形のPEが通過できるか（帰属フィルター）
  Recursive CTW B0段 — 帰属スキーマ自体のσを引き上げるメタ操作
  多様なフィードバック形式の設計
```

この分割が明示されていなかったから「CTW/DRP設計 → より強いCDMを入れる（κ↑のみ）」に陥りやすかった。

## 各ドメインへの翻訳

### ゲームデザイン
- **κ操作**: 難易度上昇（HP、ダメージ、スピード）、コンテンツ解放速度
- **σ操作**: 解法の多様性（複数クリア手段）、フィードバック形式の多様化（視覚/聴覚/触覚）、プレイスタイル包容設計
- **典型失敗**: DLCで難易度だけ上げてプレイスタイルを固定 → 燃え尽き
- **逆MBDC設計（音楽教育からの転移）**: 成熟プレイヤーのσ収縮に逆らって、意図的に新解法・新スタイルを追加

### 教育介入設計
- **κ操作**: 課題難易度の漸進的上昇、スペーシング効果設計、インターリーブ訓練
- **σ操作**: フィードバック形式の多様化、帰属介入（Wilson & Linville型）、B0段CTW開口（「困難は一時的」の正規化）
- **典型失敗**: Dweck entity score高い学習者に「もっと難しい課題」だけ設計 → 形式的コンプライアンス（外形上こなすが変容なし）
- **設計分岐**: MBDC成熟者（固定マインドセット高）ではσ設計がκ設計より先に必要

### 組織変革
- **κ操作**: 危機感醸成（Kotter 8段階の「危機の確認」）、数値目標・タイムライン設定
- **σ操作**: 心理的安全性構築（Edmondson）、変革の「形の多様化」（スタッフが異なるアプローチで貢献できる許容）、Recursive CTW型: 組織内の「変われる文化」の先行確立
- **典型失敗**: 危機感醸成（κ↑）だけで心理的安全性（σ）なし → 形式的服従（見かけ上の変革、実質的なFrozen維持）
- **Edmondson & Lei 2014の実証**: 「危機だけでは変革行動は起きない」= κ単独の限界の組織版実証

## スポーツ科学での独立実践（既存支持事例）

Schmidt Schema Theory（1975）の「バリアブル・プラクティス」がσ設計の独立実践として存在する:
- 漸進的過負荷（κ設計）とバリアブル・プラクティス（σ設計）をコーチが**独立した週次プログラム**として設計している
- 上級選手ほどスペシャリゼーション（σ低下）が進む = MBDCの精確な鏡像
- リハビリ医学: Errorless Learning（σ抑制）vs Error-Based Learning（σ拡張）を回復段階ごとに選択

→ スポーツ科学ではQSIDが**暗黙知として実装済み**だった。MBDC/QSIDは「なぜそうするか」の理論的根拠を与える。

## 使いどころ

| 場面 | 適用 |
|------|------|
| 「もっと難しくしたのに習得率が上がらない」 | κ高/σ低パターンの疑い → σ軸設計の追加 |
| 「変革を推進したのに形式的コンプライアンスに終わった」 | 同上（組織版） |
| 「固定マインドセット者には何が有効か」 | まずRecursive CTW B0段でσを引き上げ、次にκを設計 |
| 「DLC設計」 | 難易度κ設計だけでなく解法多様性σ設計を独立に検討 |

## 限界

1. **単純系での縮退**: σ ∝ κ縮退が自然な単純スキーマ（初学習者、浅い知識構造）ではQSID設計の追加コストが実質的効果を生まない。**MBDC成熟が起きているか確認してから適用**。

2. **σの2層問題**: 設計者が操作できる「入力側σ（提示刺激の形の多様性）」と、スキーマが実際に受け付ける「スキーマ側σ」は別物。入力σを多様化してもスキーマ側σが閉じていれば変容は起きない（この場合Recursive CTW B0段が先に必要）。

3. **κ-σ独立の条件付き性**: 複雑なattractorネットワークを持つ系（生物的スキーマ、組織文化）でのみ成立。物理化学的閾値系ではκにσが構造的に連動する。

## DiffMindとの接続

「κのみをパラメータ化したForwardモデルは変容の逆問題が解けない」。
σを欠落させたモデルでは「変容が起きなかった」とき「κが足りなかった」としか診断できない（実際はσの形不適合が原因だったとしても）。
→ DiffMind「逆算不可 = Forwardモデルの失格通知」の具体的適用例。

## 新予測

**P-QSID-01**（確信度: 中）:
- 予測: 同κ水準でσ設計あり群とσ設計なし群を比較したRCTで、MBDC成熟進行学習者（Dweck entity score高/習熟度高）においてのみσ群の有意な習得率優位が出る。MBDC成熟が進んでいない初学習者では差が出ない。
- 反証条件: MBDCの有無に関わらずσ設計が常に有効な場合、またはMBDC成熟者でもκとσの交互作用のみ有効でσ単独効果がない場合
- 既存予測との関係: P-κ-01/P-σ-03/P-σ-04/P-RCT-01の統合検証として位置付け可能
