## 一言で
カテゴリを正しく認識することは、そのカテゴリが物理的に許容する揺らぎのレパートリーを暗黙的に知ること。

## 構造

```
セマンティックカテゴリ
  → 物理制約束（そのカテゴリが従う物理法則の集合）
  → 制約空間（許される揺らぎの許容領域）
  → 自然実現される統計（≈ 1/f）
```

セマンティック分類は直接統計を「召喚」するのではなく、その物体が従うべき物理法則の束を定義する。
その物理法則束が「許される揺らぎの形」を絞り込み、その絞り込みから 1/f 統計が自然に現れる。

## 使いどころ

| 場面 | 例 |
|------|-----|
| ニューラルレンダリング設計 | 「髪」カテゴリを与えれば Marschner BSDF の統計が召喚される |
| AI 生成コンテンツの品質評価 | カテゴリ認識精度がスペクトル統計正確性の代理指標になるか？ |
| 教育設計 | 概念カテゴリの正確な取得 = 「正しい誤りの分布」の取得 |
| 即興演奏 | コードカテゴリを知ること = 適格な音の揺らぎのレパートリーを知ること |
| 組織設計 | チームの「意味のカテゴリ」が確立されると暗黙知が自然に伝播する |

## 適用例

### DLSS 5（発見の起源）
- 「髪」というセマンティックラベル → Marschner BSDF（R, TT, TRT 成分）の物理制約束が召喚
- per-asset 学習なしの汎化 = カテゴリ境界情報だけで bulk（pixel 統計）を定義できる証拠
- Yoneda 最小召喚原理の工学的実装例

### ジャズ即興
- コード「Gm7」を知る = そのコード上で「適格に外れていい音」の統計的分布を知る
- 初学者はコードを「ルール」として知る（Mono-Frozen 的）
- 熟達者はコードを「揺らぎの制約空間」として知る（CP 的）

### Alexander 建築
- 「doorway」カテゴリを知る = そのスペースが持つべき空間 1/f 統計の制約を知る
- Alexander 15 条件 = セマンティックカテゴリの集合として読める

## 限界

- 「制約空間から必然的に 1/f が生まれる」という論理は現段階で仮説レベル。物理系によっては制約空間が 1/f でない統計を生む可能性がある（例：結晶など Frozen 系）
- カテゴリの粒度問題：「物体」レベルのカテゴリが有効か？「マテリアル」か「動き」か「コンテキスト」か？
- 人工的カテゴリ（言語構成物）と物理的カテゴリの区別が未整理

### ⚠️ 2026-04-27 重要精密化: 地形-ダイナミクス分離

CEP が記述するのは「地形設計（Step 1+2）」であり、「ダイナミクス到達（Step 3）」ではない。

```
CEP がカバーする範囲:
  カテゴリ → 制約空間（地形）    ← CEP の射程はここまで

CEP がカバーしない範囲:
  制約空間 → SOC（ダイナミクス）  ← 別設計問題（エネルギーポンプが必要）
  SOC → 1/f（統計の創発）        ← SOCが走れば数学的帰結
```

**帰結**: CEP は 1/f の「必要条件（地形）を設計する原理」であり「十分条件ではない」。
物理系（砂山・髪物理）はエネルギーポンプが構造に内蔵されているため自動直結する。
社会/認知系（教育・音楽・建築使用）では地形の外にエネルギーポンプを意図的に設計する必要がある。

建築・音楽・教育での Step 1+2 支持（9/9）は維持。Step 3 は物理系のみ確認済み。

## 接続する既存原理

- **境界情報が本体（Yoneda 最小召喚原理）**: カテゴリ = 境界情報。bulk（統計）はそこから導出される
- **CP 普遍性原理**: 物理制約空間の自然代表が 1/f 統計（= CP）である理由
- **臨界注入の原理**: 受け手の制約空間（カテゴリ）と注入統計がミスマッチすると不気味の谷
- **決定論は CP を殺す**: 勾配降下法が制約空間を尊重せず低周波に偏ることで 1/f を破壊する
