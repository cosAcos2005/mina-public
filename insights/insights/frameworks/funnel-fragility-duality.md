# 漏斗-脆弱双対原理（Funnel-Fragility Duality, FFD）

> **一行**: 守るほど脆くなる — 保護と脆弱は漏斗の表裏
> **形式**: ∂(Attractor Coherence)/∂(Canalization Strength) < 0

## 核心

多重引力子系において、P操作（カナリゼーション）がH1β動態（旅）を守る強さと、H1α到達点（目的地）の脆弱性は**正に相関する**。これは漏斗幾何の位相的必然。

## 数学的根拠

### 1. Coherence Gap
Basin Coherence > Attractor Coherence が系統的に成立（Bavisetty et al., PRX Life 2026, 122 Boolean GRN）。カナリゼーション強度との相関 Spearman ρ = -0.997。

### 2. 漏斗幾何
有限位相空間を複数引力子が分割する以上、一つのbasinが上部で広い（多軌跡を捕獲）なら底部は隣のbasin境界に近い。広い口 ⇔ 狭い底。

### 3. Lyapunov安定性 ≠ 構造安定性
深い井戸（大きな負のLyapunov指数）と狭いbasin（余次元1の分岐面近接）は数学的に独立。basin深さ ≠ basin幅。

### 4. Fractal basin boundaries
3+引力子系ではbasin境界が一般的にフラクタル（Grebogi, Ott, Yorke 1983）。極端ケース: Riddled basins（basin内のどの開集合にも別basinが正測度で侵入）。
