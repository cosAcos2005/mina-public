## 一言で

「到達は測度崩壊 — B不可視・V可視の非対称が、到達延期を支配戦略にする」

## 構造

### 問いの核心

FFDが「守るほど脆くなる」という事実を確立した後に生じる問い:
**「では、いつ到達するべきか？」**

シェエラザード（アラビアンナイト）はこれへの最純粋な答えを持つ:
「完結（= 到達）= 死」という文脈で、毎晩「未完で終える」ことが最適戦略。

### 情報非対称の数学的起源

到達は「正測度の集合 → 測度ゼロの点」への不可逆写像（= 量子測定の一般形）。

**V(t)（脆弱性コスト）**: 現在いる「集合」の性質 → **内側から測定可能**
**B(t)（到達利益）**: 到達先の「点」の性質 → **B(t)の測定と到達は同一操作**

→ B(t)を知ることはすでに到達することであり、**到達前にB(t)を知ることは原理的に不可能**

### 停止問題の定式化

最適到達時刻 t* を求める停止問題:

```
最適停止条件: B(t*) - V(t*) = W(t*)
ただし W(t) = 残余待機価値 ≡ E(T)（接触弾力性）

B(t)不可観測時の代替規則:
「dV/dt加速（CSD指標上昇）前に到達せよ」
（B(t)が非減少かつ有界の仮定下でのみ最適）
```

### 二種の最適戦略

**Shehrazade解（恒常H1β用）**:
- V→∞またはB有界 → t*→∞（永遠に到達しない）
- 適用: 民主主義、生態系多様性、未解決数学予想、世界ロア

**SIC解（探索H1β用）**:
- B有限・V有限 → t*有限（最適時点で到達して即再出発）
- 適用: 科学的仮説検証、ゲームレベル進行、技術的実装

**判定基準**: GTH v2のH1β分類（恒常 vs 探索）

## 既存原理との関係

```
彫刻の原理: 「削るほど美しい」 ← なぜ到達したいか
FFD:         「削るほど脆い」   ← なぜ到達は危険か  
SAP:         「いつノミを置くか」← 最適停止の決定則
```

この三つが「創造と到達の完全な意思決定理論」を形成する。

**E(T) ≡ W(t)**: 接触弾力性はオプション価値の別名。
**C≈0**: SAPのコーナー解（V→∞の時の極限）。
**1/f統計**: α≈1 = Shehrazade状態の時間的指紋（到達回避の固有値スペクトル）。

## 限界と注意点

- 「dV/dt加速前が最適」は**代替規則**（正規の停止条件はB(t*)-V(t*)=W(t*)）
- 「B(t)が非減少かつ有界」の仮定下でのみ成立。B(t)が急激に減少する場合は即時到達が最適
- Schellingのコミットメント原理と**対立しない**: 固定ゲーム・短期では探索H1βとしてSIC解を使う
